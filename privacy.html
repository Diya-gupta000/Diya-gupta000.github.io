Privacy Policy

Effective date: October 27, 2026

Diya Workspace CLI is a personal desktop utility used only by its owner. It accesses Google user data only after the owner grants OAuth permission and only to perform commands the owner requests.

Data accessed

Depending on the command and permissions granted, the app may access Google Drive files, Docs, Sheets, Slides, Gmail messages, Calendar events, Tasks, Contacts, and Google Chat messages.

How data is used

Google user data is used solely to display, create, update, or organize the owner's Workspace content in response to local commands. The app does not use Google user data for advertising, profiling, or training generalized AI models.

Storage and security

OAuth credentials are stored locally in encrypted form with key material protected by the operating system keychain. Workspace content is not copied to a separate hosted database by this app.

Sharing and retention

The app does not sell or share Google user data with third parties. Data returned by Google is retained only as required for the owner's requested local workflow. Access can be revoked at any time from the owner's Google Account security settings.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions can be submitted through the public support repository.
